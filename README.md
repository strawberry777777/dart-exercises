**Name:** Bocala, Crystal Jade

## Scenario Description
An upgraded order logic system for Matcha Mori that calculates bulk item discounts using loops, custom functions with parameters and return values, and error handling (`try/catch`) for invalid inputs.

## Requirements Implemented
- **Conditional Logic:** Evaluates order thresholds to apply bulk discounts.
- **Looping:** Iterates through order counts to calculate prices.
- **Functions:** Implements custom functions with parameters returning calculated values.
- **Error Handling:** Employs `try/catch` blocks to gracefully catch bad input without crashing.
